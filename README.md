Todo el código necesario está contenido en la carpeta [BotControlCode](https://github.com/ColomboFrancisco/Control-remoto-Joystick-ESP32/tree/main/BotControlCode) Pero es importante tener en cuenta que para modificar el sitio web enviado por la esp32(o similar) se requiere editar la sección [index.h](https://github.com/ColomboFrancisco/Control-remoto-Joystick-ESP32/blob/main/BotControlCode/index.h) y no el archivo [joystick-controller.html](https://github.com/ColomboFrancisco/Control-remoto-Joystick-ESP32/blob/main/joystick-controller.html) ya que este es solo para visualizar o ejecutar el sitio de forma local y no tiene influencia sobre el sitio que aparece al conectarse a la esp.

Link del sitio predeterminado al conectarse al punto de acceso de la esp: https://192.168.4.1
